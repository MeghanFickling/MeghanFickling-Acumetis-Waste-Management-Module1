# Acumetis Waste Management – Real Earth Fixed

Upload every file in this folder directly to the root of the GitHub repository:

- index.html
- styles.css
- app.js
- README.md
- earth-realistic.jpg

The Earth image is intentionally stored beside `index.html`, avoiding an `assets/` folder path.

Your repository file list should show:

```text
README.md
app.js
earth-realistic.jpg
index.html
styles.css
```

After uploading, commit the changes and wait for GitHub Pages to redeploy. Then hard-refresh the live site with Ctrl + Shift + R.
